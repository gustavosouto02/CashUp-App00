# CashUp – App00 💸

![Swift](https://img.shields.io/badge/Swift-FA7343?style=for-the-badge&logo=swift&logoColor=white)
![SwiftUI](https://img.shields.io/badge/SwiftUI-007ACC?style=for-the-badge&logo=swift&logoColor=white)
![Xcode](https://img.shields.io/badge/Xcode-147EFB?style=for-the-badge&logo=apple&logoColor=white)

**CashUp** é um **aplicativo de finanças pessoais** desenvolvido em **SwiftUI** para ajudar jovens universitários a **organizar e controlar seus gastos de forma prática e visual**.

---

## 🚀 Funcionalidades Principais
- Cadastro de **receitas e despesas**.
- Organização por **categorias financeiras**.
- Visualização de **gráficos e relatórios** simples de gastos.
- Interface **intuitiva e responsiva** para dispositivos iOS.

---

## 🛠 Tecnologias Utilizadas
- **Linguagem:** Swift  
- **Framework:** SwiftUI  
- **IDE:** Xcode  
- **Banco de Dados Local:** SwiftData  
- **Controle de Versão:** Git/GitHub
